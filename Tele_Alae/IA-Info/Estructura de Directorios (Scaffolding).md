### Scafolding

src/
├── data/           # Archivos .json (vacíos al inicio)
├── models/         # Clases base
├── interfaces/     # Contratos (IUser, IConsultation, etc.)
├── repositories/   # Lógica de acceso a archivos JSON
├── services/       # Lógica de negocio
├── patterns/       # Clases de patrones (Strategy, State, etc.)
└── utils/          # ModalService, Validadores, etc.
